# Toque de Mulher — apresentação

Deck interativo de seis slides, com uma pessoa responsável por cada slide.

## Abrir

Abra `index.html` no navegador. Para servir localmente, execute `python3 -m http.server 4173` nesta pasta e acesse `http://localhost:4173`.

- `←` / `→`, `Espaço` ou os botões: navegar
- `N`: mostrar/ocultar as notas de fala de cada pessoa
- `F`: tela cheia
- Os segmentos no rodapé levam diretamente a um slide
- É possível imprimir ou salvar como PDF pelo navegador, em formato 16:9

O botão **Abrir o sistema** no último slide aponta para `https://toquedemulher-frontend.vercel.app/`. As fontes usam os mesmos provedores do site e têm fontes alternativas caso a internet esteja indisponível. Todas as imagens estão nesta pasta.
